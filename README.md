# raissacamargo.com

Rai's Room: the portfolio of Raissa (Rai) Camargo.

Static site, hosted on GitHub Pages. Every push to `main` goes live automatically.

`.github/workflows/supabase-keepalive.yml` pings the paintbook's Supabase database every 3 days so the free tier doesn't pause it. When redeploying the built site, keep `.git`, `.github` and `README.md`.
